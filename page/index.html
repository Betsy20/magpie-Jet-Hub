客户端怎么填


    

    
把 jet-hub/workbuddy/deepseek-v4.1-flash 换成「模型」页里任意一个即可。

  


  

    
它替你做了什么

    
    
      
  • 账号池：同一家多个账号自动轮换，配额用尽的、已过期且不可续期的自动跳过。
    • 
      
  • 静默续期：OAuth / refresh_token 到期前自动换新，并写回凭据文件，重启不丢。
    • 
      
  • 路由组：group/never-stuck 按顺序兜底，auto/<model> 按额度择优。
    • 
      
  • 模型目录：每家按自己账号实时拉，不写死。
    • 
      
  • 积分与签到：本体自带的额度查询与每日领取。
    •

完整控制台

    

      登录 / 换号 / 静默续期 / 积分领取 / 模型开关 / 账号池 / 备份导入导出 ——
      全部由插件自己的本地服务提供，在浏览器里打开这个地址即可用。
    

    

      为什么不能直接嵌在这个页面里：magpie 的插件页被沙箱成
      sandbox allow-scripts，策略里写死 connect-src 'none' 与
      frame-src 'none' —— 页面既发不出请求，也嵌不进框架。这是 magpie 的安全设计，
      页面只能读 providers:list 和 usage:summary 两项。
      所以「全部功能」走本地控制台，本页负责把地址给你。
    

    

      
      
      
    

    

      端口默认 18500，被占用时会自动 +1。准确端口见
      ~/.config/magpie/jet-hub-console.json 的 url 字段。
    

  


  

    
控制台里能做什么

    
    
      
  • 账号— 每个 provider 的账号池：增删、启用/停用、看有效期与续期状态
    • 
      
  • 登录— 起设备码/浏览器登录取凭据，直接落进账号池
    • 
      
  • 积分— 查每个账号的积分余额、每日领取、领取记录
    • 
      
  • 模型— 模型开关、禁用列表、按账号的限流
    • 
      
  • 路由— 聚合路由顺序、auto 选路、拒绝记录
    • 
      
  • 备份— 账号池导出 / 导入，换机器搬运用
    •
