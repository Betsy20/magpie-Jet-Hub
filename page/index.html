deepseek-harness-codearts 插件本体在 magpie 里跑 —— — 家 provider 的账号池、静默续期、积分选号、模型目录与路由组原样复用。

连接窗口… — 个模型

接入点

网关 http://127.0.0.1:3425
模型前缀 jet-hub/
鉴权 无需 API key（本机回环网关）

凭据直接用 DSH 里已经登录过的那些账号（~/.dsh/.credentials.yaml），在 magpie 这边不需要再登一次。

客户端怎么填


    

    
把 jet-hub/workbuddy/deepseek-v4.1-flash 换成「模型」页里任意一个即可。

  


  

    
它替你做了什么

    
    
      
  • 账号池：同一家多个账号自动轮换，配额用尽的、已过期且不可续期的自动跳过。
    • 
      
  • 静默续期：OAuth / refresh_token 到期前自动换新，并写回凭据文件，重启不丢。
    • 
      
  • 路由组：group/never-stuck 按顺序兜底，auto/<model> 按额度择优。
    • 
      
  • 模型目录：每家按自己账号实时拉，不写死。
    • 
      
  • 积分与签到：本体自带的额度查询与每日领取。
    •
